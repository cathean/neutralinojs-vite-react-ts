# NeutralinoJS, Vite, React, TS Template
NeutralinoJS with Vite, React, Typescript template

Already support hot-reload and configuration

# Usage
```
# Install
neu create myapp --template cathean/neutralinojs-vite-react-ts
cd myapp

# Run the app
neu run

# Build the app
neu build
```
